## 已实现

- 正式新增 0.2.0 Schema 与生成类型，同时保留严格 0.1.0 原件。新版增加服务点 zoneId 和 arrival；旧图读写/摘要不自动迁移。显式升级只改 schemaVersion/revision，可撤销、重做，完整保留 ID、来源、资产及扩展。
- 设施 yard/assembly 和独立 Zone 均可显式关联服务点。主归属互斥，区域成员由 servicePoint.zoneId 派生；没有按名称或点落入多边形猜测归属。
- 模块化服务创建/属性面板，真实画布选择已有节点或专用节点坐标。专用节点与服务点同一事务创建；保留原入口、设施、道路和物理属性编辑。
- 边界代理 node_proxy 需要明确场内转运假设；explicit_internal 保存有序道路引用，设施入口或显式 entryNodeId 为唯一接续起点。节点/方向/首尾/连续性错误不能以同设施或同坐标跳过。
- 无 DOM 接路检查，展示端点道路、到达声明、内部派生长度、blocked/unchecked 和尚未检查的能力。不生成完整可达路径，不执行车辆运输。
- 区域移动/旋转策略、复制闭包和删除依赖。内部路径复制须显式纳入全部道路；被路径引用的道路拆分仍拒绝。共享节点更新、失败原子性、稳定重做 ID 延续。
- 对象/工具/历史等导航保护未应用输入；默认取消保留，明确丢弃后才继续。未完成绘制期间不能并行编辑属性/地图名称，属性未应用时禁拖动。暂存输入不冒充已保存地图。
- 浏览器升级先成功保存原图备份，再提交升级事务并解除原文件关联；CLI `map:migrate` 用公共 load/validate/command/serialize 路径输出新文件，拒绝原地或覆盖已有输出。

单服务点仍只有一个 kind；尚未增加 supportedOperations 多操作能力。运行配置和剩余作业时间没有写进静态地图。资源、转向、底图及行为扩展原门禁保留，仅允许不改变其声明数据的显式版本升级。

## 仅有接口、未实现与限制

- SceneSnapshot 为实际二维快照，包含派生区域成员和服务到达声明；坐标继续使用本地 m、rad、kg、s。SimulationAdapter/RuntimeStateMessage 仍为既有合同，未提供到达、等待、装卸事件引擎。
- 完整路网发布、允许转向编译、资源竞争、货物状态和回放均未实现，非 draft 配置仍返回 unsupported。局部接路不是现实可达或工程安全认证。
- 边界代理处在厂房内部会提示核对，内部路径只查声明连接；扫掠、穿墙几何检测、净空/承载及真实入口可行性仍未验证。
- 内部路径每条最多 2048 弧；整图服务检查有明确计算预算。JSON 仍受 10 MiB 等已有上限限制。过大或不受支持的输入报错，不静默跳过关键接续检查。
- 未应用输入只保留于当前界面，自动保存/刷新恢复的仍是已提交地图。浏览器存储可被清理；外部原件需单独备份。
- 系统原生文件授权/任意磁盘写回的手工步骤没有在本批完成。既有自动化 API/OPFS 替身回归不能替代该手工验收。
- 底图标定、assets/ZIP 归 M2B；3D、VR、物理引擎和复杂优化器未实现。Vite 单包体积提示仍存在，未通过调高阈值隐藏；本批未做与服务契约无关的打包优化。同址实体的图形标签仍可能重叠，可通过对象列表与稳定 ID 选择。

下一阶段先审查 [M3A 实施计划](M3A_IMPLEMENTATION_PLAN.md) 中 scenario/转向/资源/事件合同，然后逐批开展服务目标可达性、必要资源编译和无 DOM 单车/双车测试。M2B 可独立补真实布局依据；本轮没有提前进入这些实现。
