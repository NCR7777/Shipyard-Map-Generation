# 02｜界面与交互规格

所有尺寸和点击次数为本次设计验收目标，不是声称当前已达到的指标。依据用户桌面使用场景；可访问性参考W3C，不能仅凭字号和尺寸宣布WCAG全面合规。[W01,W02]

## 1. 主窗口

```text
┌ 文件  编辑  视图  检查  发布       工程名称       已恢复/文件待保存   保存 ▾ ┐
├ 工具条：选择 | 道路 | 设施 | 区域 | 服务点 | 测量     撤销 重做   搜索 ┤
│ 左：对象/图层  │                                              │右：属性│
│ 搜索与筛选    │                   主画布                      │选择相关│
│ 设施/道路/... │        当前工具的局部提示与尺寸预览            │高级折叠│
│ 眼睛/锁      │        视图缩放/适应地图/小型比例尺            │操作预览│
├──────────────┴──────────────────────────────────────────────┴────────┤
│ 问题 3 | 路线 | 统计 | 来源     ← 默认收起，可拖高的单一底部抽屉        │
└ 当前工具/一步提示   X/Y(m)    吸附状态    选中数量    地图版本摘要按钮   ┘
```

顶部菜单约48px，工具条40px，底栏28px；不要把历史M2A/P2A/TE01标记放在用户主界面。
左右面板可拖宽、可折叠；推荐左240px、右300px。高频按钮34–40px；长说明进入“为什么/详情”而非常驻。
主数据名称可见，ID默认次要、可复制。右侧不再把所有诊断永久排在选中对象属性前面。

### 响应式规则

- 1920×1080：左右面板可同时常开，问题抽屉默认收起，选中对象不能改变画布大小。
- 1366×768：采用紧凑工具条；主画布可用宽度≥700px、高度≥500px为目标。工具名称可以缩短，但保持工具提示/可访问名称。
- 1093×614（用于覆盖常见缩放后的有效CSS视窗）：左侧默认折叠，右侧按需覆盖式抽屉。默认画布至少约700×430px；绝不为了容纳表单产生全页面水平滚动。
- 200%浏览器缩放：常用表单仍能访问，画布可以作为可滚动/可缩放的二维区域；不能简单以“专业软件”为由把所有按钮藏到页面外。
- 模态框有max-height和内部滚动；取消/确认固定可见。提示或错误出现时不挤压画布、不改变指针命中位置。

设计规范目标：正文14px，辅助信息12px，数字等宽；次要色不是浅到难读。普通文本对比度目标4.5:1，重要边框/焦点可辨；最终逐项验证，不凭配色印象验收。24 CSS px是W3C最小点击目标的一般规则，包含间距/必要空间等例外；本产品高频控件主动采用更大目标。密集几何点不机械画成24米/24屏幕像素巨点，提供对象目录和精确坐标作为替代。

## 2. 工具与状态

使用一种工具状态模型，不维护多个相互矛盾的“正在绘图/正在选点/正在拖拽/弹窗中”总开关。
持久状态（YardMap）、用户偏好（EditorState）、当前会话草稿（InteractionState）、派生视图（SceneSnapshot）、外部运行覆盖（RuntimeOverlay）分开。

建议状态：idle；selecting；panning；drawingRoad；drawingPolygon；editingVertices；placingPoint；measuring；previewingOperation。属性表单草稿独立但只有一个活动目标；危险确认通过一个有类型的dialog描述，不用十几个独立布尔量。
每个草稿绑定projectId、mapContentHash/changeToken；工程/图变化后不能提交旧草稿。相机拖动本身不能导致草稿失效。

### 统一行为

- 点击对象：选择；再次点击不偷偷开始拖动。拖动超过约4 CSS px才进入移动预览，阈值为UI选择。
- 空白拖动：框选。左→右完整包含，右→左相交选择；矩形颜色和状态文字表明规则。提供菜单替代。
- Shift+点击：增减选择；在绘路状态下Shift改为正交约束，不同时触发多选。
- 中键拖动或按住Space+左键：临时平移；松开恢复原工具；失焦恢复，Space不锁死。
- 滚轮以指针为缩放锚点；触控板策略与浏览器行为明确区分，不截获整个页面的缩放。
- 选中多个重叠对象：Alt+点击循环或“选择重叠对象”菜单列出候选。被遮挡的节点/道路/服务标记可从目录明确选择。
- Esc：先取消当前局部预览；再回到选择工具；无活动草稿时才清空选择。已经完成的操作只能通过撤销取消。
- 长按方向键微移：步长可见且可设置，例如0.1/1m；一次按键连续会话合并一个事务。数值输入等价可用。
- 滑块、拖角和连续输入只预览；结束/确认形成一次领域事务。
- 失败保留输入和当前有效图，定位失败对象，不把表单全部清空。

## 3. 键盘与焦点

| 按键 | 行为 |
|---|---|
| V / H / R / B / G / M | 选择 / 平移 / 道路 / 设施 / 区域 / 测量 |
| Space按住 | 临时平移 |
| F / Shift+F | 适应地图 / 定位选中 |
| Ctrl/Cmd+Z；Ctrl/Cmd+Shift+Z | 撤销；重做；Windows Ctrl+Y保持可用 |
| Ctrl/Cmd+S | 统一保存流程（第5节） |
| Ctrl/Cmd+K | 命令搜索；按中文名称检索功能，不要求记快捷键 |
| Delete | 删除预览；无依赖简单对象可以按约定单次删除并撤销，复杂对象明确确认 |
| Enter | 完成当前绘制/应用有效输入；不触发未知对象的危险默认动作 |

快捷键只在编辑工作区激活，input/textarea/select/contenteditable、IME组合输入及模态框优先。文本框中Ctrl+Z撤销文本，不撤销地图。对话框焦点陷阱、Esc取消、关闭后焦点返回触发按钮。禁用按钮不能只靠hover title解释，旁边有可聚焦“原因”入口。

## 4. 常用工作流

### 4.1 画一条平直道路

选择道路工具 → 点击起点 → 点击终点或Enter结束；空白端点由同一个复合命令创建必要节点。默认得到两端点、一条直路、零内部折点。开启连续折线才让中间点击成为形状点；“道路形状点”与“路网连接节点”明确不同。
绘制时显示长度、方位角和吸附目标。角度在UI用度，可输入0/45/90等；写入模型仍为rad。宽度/方向沿用用户显式选择的绘图模板，不把默认值宣称为实测。
吸附模式分为“坐标对齐”与“建立连接”。后者必须明确拆路/复用节点/新增转向影响；前者不产生拓扑。绘制中间跨过其他道路默认不连接，完成时列出未处理交叉候选。
对复杂依赖路口先预览再提交，取消不留下孤立节点或半条道路。

### 4.2 修正一条道路

点击道路 → 局部工具条出现“编辑形状、插入连接节点、拆分、方向、删除”；直接拖形状手柄不必先到右边填坐标数组。
选中两端一起平移时预览邻接道路被拉伸的效果；有设施内部所有者时提供“编辑所属通道/整体移动设施”入口。不能只回报LOCAL_OWNER_DEPENDENCY后让用户自己找JSON。
“删除多余节点”默认保持原中心线几何：弯点转为shapePoint；只有用户明确选择“拉直”并通过冲突检查才能改变路线。批量简化必须预览每个候选及不能删的原因，不能删除服务节点或转向语义。

### 4.3 建筑与堆场

创建矩形使用两角点击/拖动＋宽高数值两种方式。拖矩形角保持直角，固定对角，宽高可独立；旋转建筑沿自身轴调整。多边形、孔洞有单独模式，不能把任意四边形自动矩形化。
右侧默认只显示名称、类别、位置/尺寸、旋转、关联服务数量和“应用/恢复”。来源、全部顶点、资源依赖展开查看。
普通建筑优先“移动边界＋入口/服务/内部内容（按依赖可行策略）”的可解释操作；不能静默保留门洞在原地。若用户选择“只改边界”，提交前列出点位/储位越界情况。

### 4.4 服务点向导

选设施/区域 → “添加交接点” → 在画布选择位置和所属入口 → 选择边界交接或显式内部通道 → 预览接入 → 提交。
业务名优先：“边界交接点（场内转运计入服务时长/明确不计）”“内部交接点（需要内部通道）”。不要在所有场景无条件推荐node_proxy。
内部路径按连续可选道路高亮；只能选择符合方向和节点连续性的下一段，支持返回/清空/整体预览。显示本地到达不等于完成装卸。可以存未完善草稿，但发布需要说明缺项。

### 4.5 路口与储位

路口选中后显示入口方向和转向矩阵：允许、禁止、未声明三态；一格一条movement，不由画线颜色推断。批量批准前列出范围和保留禁转规则。
选堆场可配置储位长宽、行列、间距、保留通道、排列朝向，预览可容纳几何，不自动映射为实际生产能力。支持删除/调整指定储位与明确重新生成；重新生成必须显示ID和容量变更，不静默全体重编号。

### 4.6 检查与修复

检查结果按“阻止发布/待确认/未知参数/未检查能力”分组，而不是同屏铺满原始代码。每项有：中文问题、对象名、定位、建议动作、详情。点击“修复”必须走已有命令预览，不建立第二套修图逻辑。
对外部原始地图已有冲突允许保留可读草稿；不通过删除障碍让道路通过。已检查0错误与检查未运行是不同状态。

## 5. 保存、人机工程与数据安全

主按钮“保存”明确目标：有已授权关联文件则保存到该文件并保持浏览器恢复；没有关联文件时显示“保存到文件/仅保存浏览器恢复”的一次选择，并记住用户选择。Ctrl+S走同一入口。文件选择器不支持时降级为下载，不声称已写回源文件。
后台自动保存仅更新浏览器恢复状态。顶部显示精简但真实的两项：“浏览器恢复已保存”“本地文件有未写回变化”。历史上导出JSON不确认文件保存的语义必须保留。
未应用表单遇到保存：提供“应用后保存 / 保存已提交版本 / 取消”。绘图未完成不能自动闭合，应明确提示完成或保存旧版本。
文件与浏览器保存不是跨存储原子事务：文件失败但恢复成功时准确显示部分成功；不能显示统一绿色“已保存”。离开工程前仍有未保存变化则恢复副本/另存/取消可选，外部文件冲突必须保留双方。
普通视图操作、折叠面板、筛选、比例尺不改变mapHash。所有实体修改经命令更新来源与派生失效。

## 6. 交互完成目标

简单直路：选中道路工具后2次几何点击即可完成；有连接冲突允许增加一次明确确认。
选择并定位对象：搜索输入＋结果一次点击；不能要求复制粘贴长ID。
调整矩形宽高：一次选择＋数值输入＋一次应用；无需浏览全部顶点。
打开诊断并定位首项：一个检查入口＋一个问题点击。
“无改动、取消、失败、过期候选”不得改变mapHash、revision、历史或文件基线。
这些目标用真实鼠标/键盘完成，不只测试handler直接调用。
