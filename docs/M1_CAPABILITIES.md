## 已知限制

1. 输入文件与规范化后的两空格 JSON 都限制为 10 MiB，最大 64 层嵌套；编辑事务超限时拒绝，避免导出自身无法重新导入的地图。实体 ID 必须全图唯一，名称独立，可用中文。
2. M1 的几何长度是 XY 水平折线长度，保留 Z 但不计算坡道三维长度。节点/道路外观不会改变通行语义。
3. 所有高级数据整图只读，无法只编辑其节点再假定附属设施或人工通行带仍然一致。外部工具可以修改 JSON，但仍须重新走同一校验/导入路径。
4. 多边形几何、平交分类、转向可达性、资源执行、物理净空、二进制资产可用性和来源真实性列为未检查；草稿有效不能消除这些边界。
5. 下载使用新文件，不自动覆盖磁盘原件；不监听外部编辑。会话以“已发起导出请求”的地图摘要更新保存基线，浏览器接口不能证明文件已实际落盘；用户需确认下载未被取消/阻止并保留文件。浏览器关闭前需导出，M1 没有自动恢复承诺。
6. 摘要依据规范化声明数据，排除 revision，包含来源、扩展和资产声明；未读取的图片字节变更无法被 M1 自动检测。
7. 历史上限为 100 个领域事务，较早历史会被释放。复制闭包中任何实体带 extensions 时，M1 以 UNSUPPORTED_COPY_SEMANTICS 拒绝复制，避免错误改写未知扩展引用；原图与历史不变。
8. 含数字的名称不会随几何变化自动更新。例如“100 m 合成道路”改为 120m 后，名称仍需用户自行修改；派生长度才是几何计算结果。

9. 手动几何编辑保留用户原来源声明，不会自动证明修改后的坐标仍受该来源支持，也不自动改写 surveyed/reference_based 标签。M1 界面提示未重新核验，用户需同步外部字段依据；来源失效与重新确认工作流留待 M2。

10. 极端但有限的坐标可能超出画布可投影范围；此时跳过对应屏幕图元并显示数量提示，保留 JSON 和对象列表。适应地图不会写入非有限视窗值；这不是超大场景性能承诺。
