## M1.1 验收范围

| 要求 | 证据路径与判据 |
|---|---|
| S01/S02 | 真实浏览器 IndexedDB：不下载也可自动保存、刷新、关闭后重开；多项目与各标签页恢复不串项目 |
| S03/S04 | 延迟恢复不得写空图；保存 A 期间编辑 B，A 确认不把 B 标为已保存；故障注入与真实浏览器部分分别标注 |
| S05/S06 | 事务失败、配额/权限/取消保护；真实双标签页独立存储版本 CAS，冲突支持重载及恢复副本 |
| S07 | 外部文件原字节摘要变化、共同 JSON 导入/校验路径、显式重载/另存/覆盖；原生授权列出手动验收 |
| S08/S09/S10 | 输入焦点先处理保存快捷键；文本撤销/删除保留；下载、浏览器、本地文件确认基线独立；未应用输入单独提示 |

浏览器工程存储版本独立于 map.schemaVersion/revision；map JSON 与 editor-state 分开存储。浏览器保存不是永久备份。本地文件能力渐进增强，原生选择器必须由用户点击触发；流关闭成功才确认。未知高级实体与扩展仍完整保留并受当前能力门禁保护。

## M2A 验收范围（保存阶段通过后实施）

- 使用已有 Facility、Zone、AccessPoint、ServicePoint；不新增另一套画布地图。同步 commands/Selection、capabilities、SceneSnapshot/compiler、MapCanvas、分类型属性面板、持久化与校验。
- 矩形/多边形设施，作业/缓冲/等待/水域/障碍区域；数值、移动、旋转、顶点编辑、多选、复制、删除、撤销重做。
- 入口/服务点坐标仍来自 nodeId；双向成员关系在一个事务中维护。移动前明确是否连同关联点；共享道路节点影响有预览。设施复制闭包明确断开外部路网，不复制整个路网。
- 按任务书 4.5/G06/G09 实现显式插入/拆分、网格/节点吸附、近邻未连接提示及四状态道路物理参数编辑。不能把普通相交变成连接，不能丢失方向/来源或猜测未知 movement/resource/extension 重写。
- G01—G10 分别验证 60m×30m 保存往返、引用、原子闭包、拖动历史、多边形基本几何、拆分长度守恒、旧样例、缺失背景、物理状态、无 DOM 运行。

M2B 底图标定/二进制资源/完整 ZIP 往返和 M3 网络发布/路径预览随后单独验收。本轮不做三维、VR、复杂调度或装饰车辆动画。存在接口不等于功能运行；几何草稿有效不等于车辆运输物理安全。
