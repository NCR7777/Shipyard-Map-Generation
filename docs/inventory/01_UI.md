### 2.2 保存（saveProject 438，persistTargets 468）

- 保存 / Ctrl+S：浏览器 checkpoint + 写回已关联文件，分别报告；文件关联在浏览器保存成功后持久化。
- 未关联文件：不弹选择器、不下载，报告「未写入本地文件」（SV02）。旧 saveTarget 偏好不再影响默认保存。
- ▾：仅保存浏览器恢复、另存为。
- 有未应用输入：取消 / 仅保存已提交地图 / 应用后保存；绘制未完成时「应用后保存」禁用，不自动闭合（applyThenSave 454）。
- 浏览器状态 11 种（useProjectWorkspace.ts:250），本地文件状态 6 种（App.tsx:1140）。
- beforeunload 在有待定相机、浏览器草稿未保存或未应用输入时拦截（969）。

### 2.3 自动保存与恢复（useProjectWorkspace.ts，projectController.ts:216）

- 地图变化 600ms 防抖写 draft（163-170）；EditorState（相机、绘图配置、工作台、单位、底图偏好）单独 600ms 防抖（172-179）。仅改配置不改地图 JSON、revision、哈希、历史（D02）。
- IndexedDB：每工程 draft、checkpoint、previousCheckpoint 三份，CAS 存储版本；恢复顺序 draft → checkpoint → previousCheckpoint，损坏跳过并警告。
- 启动优先恢复本标签页 sessionStorage 工程，其次全局最近工程，否则新建。
- 恢复完成前模态「恢复浏览器工程」，恢复前绝不写空图；失败时「重试恢复」「仅内存继续编辑」。
- 刷新后回到选择工具，不恢复自由多边形模式、弹窗或未完成输入（D08）。EditorState 损坏时警告但仍恢复地图（D06）；旧 camera-only 记录补默认值（D05）。

### 2.4 冲突

- 其他标签页保存了同一工程：获焦时检测 storageVersion，红条；「保留当前恢复副本」或「重新载入浏览器版本」（取消 / 保留副本 / 明确放弃并重载）（1221、1227）。
- 外部文件被改：对话框（1228）取消 / 重新载入文件 / 保留当前恢复副本 / 文件另存为 / 先保存双方恢复副本；之后才出现「明确覆盖外部版本」，由 overwriteToken 绑定当前哈希；外部文件非法时不允许覆盖。
- 导入时有未保存编辑（1234）：取消 / 先导出当前版本 / 放弃编辑并重载；非法候选在弹框前拒绝。
- 坐标框架替换（1224）：重新载入文件、浏览器版本或重试恢复时确认。

### 2.5 Schema 升级（upgradeSchema 402，对话框 1238）

0.1 → 0.2：地图信息中「升级到 0.2.0」。0.2 → 0.3：选择道路、弯曲、建筑、区域工具或首次生成研究接入建议时触发。流程：原版备份为浏览器工程 → 解除文件关联 → 提交可撤销的升级事务；对话框「导出升级前原图」「保留原图并升级」；完成后切到原先要用的工具。

## 4. 绘制工具（MapCanvas.tsx:35，changeTool App.tsx:394）

0.1/0.2 地图选择道路、弯曲、建筑、区域工具时先要求升级到 0.3。

### 4.1 道路 R（traceRoadPoint 669，finishRoad 662；quickTraceRoad drawingDefaults.ts:107）

- 起点：点空白自动建端点；点节点或离中心线 12px 内出现绿圈目标即明确接路，点在道路中部会原子拆路（traceCandidate，MapCanvas 472）。
- 中间点只是几何锚点，不是网络节点。
- 结束：Enter、双击、「完成道路」，或点到接路目标自动结束。
- Alt：本次点击和整条草稿都不接路。
- 自动平交：「本项目新路平交相连」开启时，与新画道路的交叉点在停顿 100ms 后显示「+ 连通」预览，完成时生成路口；Alt 禁止（useCrossingPreview，MapCanvas 706）。
- 默认：宽 12 m、双向，来源 design_assumption quick_trace_v1；名称「道路001…」；明确接路时生成非掉头转向；限高、承载、速度未知。
- 整条道路一次撤销；完成后选中新道路，工具保持，可连续画。至少两个不重合的点。Esc 直接丢弃草稿（无属性脏数据时）。

### 4.2 弯曲 C

依次点起点、终点、弯曲经过点（appendDraftCurve，roadDrawing.ts:22），单独画曲线时第三次点击完成；同一草稿内按 R/C 在直线段与曲线段之间接续；「本次接续」折角/平滑（平滑只调整本次草稿切线），说明条显示当前接续；终点与起点重合时报错。

### 4.3 独立节点

点空白创建，名称「节点 N」（1213）；无快捷键，另一入口在设置区。

### 4.4 建筑 B / 区域 A、G

形状：两点矩形、三点矩形、多边形（useSpatialDrawing.ts:28）。两点矩形点两对角或拖出（>5px）；三点矩形先点基边两端再定宽，保持直角并有最小尺寸；多边形逐点，Enter / 双击 / 点回起点 12px 内 / 「完成多边形」完成，Shift 约束水平垂直，Esc 或「取消绘制」取消。左上显示分步提示。提交 addPolygon 651：通用类型走 quickTraceBoundary（名称「建筑001 / 区域001」，带默认分类），非通用类型走 addFacility / addZone。工具保持，完成后清空选择。B = 两点矩形建筑，A = 多边形区域，G = 两点矩形区域（会重置形状下拉；三点矩形无快捷键）。

### 4.5 量距 M（useMeasurement，MeasurementOverlay.tsx:8）

连续点击折线量距，读数「预览 / 已定 / 总长」；Enter 完成、Esc 清空；不写入地图与历史；切换工具或地图时清空；非描图工作区可用。

### 4.6 「绘图与显示设置」（App.tsx:1168-1185）

拓扑吸附；节点/中心线接路吸附（Alt 临时关闭）；本项目新路平交相连；网格吸附 关闭/1/5/10 m；高级绘图兼容类型（建筑 building/workshop/other，区域 unclassified/work/buffer/waiting/water/obstacle/forbidden/drivable）；按钮组（节点、矩形建筑、三点斜矩形建筑、多边形建筑、矩形区域、三点斜矩形区域）；添加入口、添加服务点；道路显示（道路带 / 中心线 / 普通节点，默认关）；恢复绘图默认配置（连同图层显隐和锁定一起重置）；选中设施或区域时的移动影响说明。

### 4.7 吸附

节点吸附：12px 内吸附同 Z 节点；网格吸附四舍五入（snapPosition，useSpatialDrawing.ts:13）。坐标吸附永不建立拓扑（G06/G09），只有绿圈明确接路或拓扑吸附确认才连接。

### 4.8 入口与服务点

连续添加入口（armContinuousEntrances 683，pickPoint 708，PointCreationPanel.tsx:111）：选中建筑后点「添加入口」，高亮外环，靠近边界 12px 出现绿色吸附点；每点一次立即创建入口与独立节点（名称「入口001…」，取首个未用编号）；在已有入口上点击或双击不重复创建；孔洞与远离边界处无效；Ctrl+Z 逐个撤销且仍可继续；Enter、Esc、「完成添加入口」、切换工具或对象退出；连续模式中可直接保存；「单个入口与接路设置」转入单点流程。

单点创建（ConnectedPointFields.tsx:9）：「创建时接路」两种——先放置节点稍后画路（deferred：不接路、不声明到达，点位须在所属对象内，入口须在外边界上且不在孔洞里）；创建时明确接路或到达方式（connected）。字段：名称、所属对象；作业点另有作业类型（装载/卸载/停车/泊位/其他）、经过入口、到达语义。画布拾取：放置位置、选择接入道路（中部接入显式拆路）、选择连续内部路径（绿为已选、青为可继续）、选择区域入口、直接从入口连到作业位置、重选内部路径。新接入段方向与宽度留空表示未知。预览列出建议转向，可用模板（仅驶入 / 仅驶出 / 明确双向 / 清除本次许可）或逐项勾选，默认不放行任何转向。作业点可复用已有资源（容量不变）。已有接路候选时「打开高级关联表单」禁用。connected 切回 deferred 需确认。点位落在水域、禁行或障碍区时提示。

高级表单（PointCreationPanel.tsx:107）：选已有节点或新建节点（XYZ 或画布放置），一个事务。入口：设置区「添加入口 / 添加服务点」（openPointDialog 737）；设施与区域属性面板「编辑内部 / 添加入口 / 添加作业点」（placeAction 745）。

### 4.9 草稿生命周期（useEditorInteraction.ts:43，drafts.ts:20）

同一时间一个活动（relocate、road、polygon、point、boundary、splitPick）加一个有类型的对话框，都绑定 {projectId, changeToken, mapContentHash}，过期不能提交（STALE_EDIT_CONTEXT）；相机移动不使草稿失效。「未应用输入」（App.tsx:252）包括属性面板脏数据、地图名称、道路草稿、多边形草稿、非连续模式点草稿、重新定位、底图候选或表单、复制/旋转/拆分对话框、拆分拾取、拓扑草稿、分类对话框。离开动作经 requestLeave（363）弹「未应用输入保护」（取消保留 / 丢弃并继续，1237）。只改显示的配置（搜索词、标签模式、透明度）不触发保护，其它配置修改会触发（updateDrawingConfig 297）。

## 5. 选择与变换

### 5.1 选择

单击选中，Shift+单击增减（加选不移动相机，R07），点空白清空。叠放循环（cycleAtPointer MapCanvas 332；selectionHits.ts:21,59）：同处（6px）再次点击或画布聚焦时 Tab/Shift+Tab；优先级 服务点 > 入口 > 节点 > 道路 > 建筑 > 区域；提示「叠放对象 i / n」；排除隐藏类型，锁定类型仍可选中查看。同一 nodeId 上的多个入口/作业点合并为一个标记（「入/作」「入N」），点击弹身份选择器（AssociatedPointLayer，SpatialLayer.tsx:116）。厂界、路口、储位可在画布点击，资源与转向只能从目录选；这些只进入检查模式（ObjectInspector + 只读 JSON），与编辑命令混用时拒绝（INSPECTION_SELECTION_READ_ONLY）。无框选、无 Space 临时平移。

### 5.2 移动

节点先选中再拖（第一次按下只选中，拖不动时 explainDrag 909 说明原因）；设施、区域、入口、作业点可直接拖主体。刚体移动策略写死为 withStaticContents（App.tsx:100）：私有内容（储位、私有节点、内部道路、入口）一起平移，公共路网锚点固定；属性区显示影响说明，受限时「当前移动受限」（1185、1192）。拖动实时预览，松开提交一个事务（100 步一次撤销）；零位移拒绝；Esc、失焦、指针取消撤销预览。Alt+拖动在偏移处复制（MapCanvas 570、578）。有未应用输入时禁止拖动。

### 5.3 复制、旋转、删除

复制对话框（1235）：显示闭包数量（道路端点、设施/区域成员自动纳入），输入 XYZ 偏移，可选「允许单独复制的入口/服务点关联原设施」，外部道路不复制。Ctrl+D 快速复制，偏移 (+10, +10, 0)。旋转（1249）：°/rad、旋转中心 XYZ、影响道路；属性面板另有数值旋转。删除（Delete/Backspace/工具栏，1239）：三项勾选——允许级联删除关联道路、转向、空路口（资源容量保留）；一并删除成员入口与服务点；清理不再使用的节点；列出影响清单，依赖无法维护时整笔拒绝。

### 5.4 边界控制柄（BoundaryHandles.tsx:30，commitBoundary 347）

显示条件：单选一个设施或区域、选择工具、无草稿或未应用输入、类型未锁定、canEditBoundary。矩形模式 4 个角柄，拖动时固定对角沿局部轴改宽高，最小 0.01 m，越过对角夹到最小值，显示「局部宽 × 高」，与缩放无关（R03）。自由多边形模式：顶点柄（孔洞紫色）、边中点绿色插入柄、Alt+点击顶点删除。松开提交一次；不合法回退报错；零面积拒绝且不产生撤销步（R04）；Esc、失焦、地图修订变化取消（R05）。设施边界违反所有权约束时弹「轮廓局部修复预览」（1232），虚线显示拟修正的专用入口，确认后一起提交；储位越界只能拒绝。模式切换在属性面板「边界编辑模式」（会话状态）。

### 5.5 道路几何柄（RoadGeometryHandles.tsx:16）

选中单条道路（选择或弯曲工具）时显示内部锚点柄（黄）、三次曲线两个切向柄（蓝）、每段中点弯曲柄（仅 0.3），拖动使直线鼓成曲线，双击弯曲柄恢复直线；松开提交一次；内部编辑模式下公共道路不显示控制柄（UX02_extra）。

### 5.6 宽度柄（MapCanvas 673）

选中单条已知宽度道路时中点两侧各一个绿色侧柄（离中心至少 16px，有引线指向真实边缘），拖动预览「人工影像估计宽度 x m」，松开以 updateRoadBatch 提交，来源 manual_image_estimate；零位移不提交。

### 5.7 其它编辑模式

编辑内部（placeAction('enter')，inInternalScope 924）：只改明确归属该设施的点和道路，公共路网固定，不允许新增道路或建筑，Esc 或横幅退出，所属对象被撤销时自动退出。在画布重新定位入口/作业点（relocatePoint 754）：点新位置，入口吸附外环，Esc 或失焦取消。建立独立入口并保留接路（PointPropertyPanel.tsx:101，EA01）：给出建议距离，把原接入段拆成公共段与内部段，入口改引用新节点，公共节点不动。

## 6. 属性面板与数值规则

- 只提交真正改变的字段（changedFields）；显示单位不回写未编辑的精确值；同值提交报「内容未变化，未创建事务」。输入框 Enter 应用、Esc 取消，输入法组合期间不触发（propertyKeys 1078）。失败保留输入与当前有效地图。未应用编辑经离开保护（DP16、P1 A03 A06）。单位：质量 t/kg，速度 km/h、m/s，角度 °/rad，存 EditorState，存储始终 m/kg/m/s/rad。有字段来源时显示「字段来源」。
- 节点（PropertyPanel.tsx:50）：名称、X/Y；技术详情中 ID（只读）与 Z；连接道路数。
- 道路：名称；派生长度；宽度（数值 + 状态：待设置/明确无限制/不适用/已声明，加依据来源；已知值无来源时自动生成「道路参数设计假设」来源；清空即未知）；方向（待配置/沿箭头单向/反向单向/双向，单向时可「反转行驶方向」）；「连续路段一起修改」（RoadBatchPanel，范围在岔口、方向、宽度、所有者或资源变化处停止，统一宽度留空表示改为未知）；「用于随后新建道路」（确认后设为新路默认值）；限制摘要；「通行限制与来源」（净高、承载、速度及单位，超出显示范围提示）；「技术详情与折点」（ID、起终点、内部锚点 XYZ 编辑，仅折线，添加删除锚点时画布实时预览）。
- 设施与区域（SpatialPropertyPanel.tsx:40）：名称；高级兼容类型；区域通行声明（未知/允许/禁止/仅显式接入）；建筑或区域分类带色块，干船坞可填深度、参照面与来源；派生量（包围盒宽×高、净面积、入口数、服务点数、高度、区域作业点数）；按钮 编辑内部 / 添加入口 / 添加作业点；矩形时「边界编辑模式」（矩形约束 / 自由多边形）；矩形约束下宽高与「固定对角」；自由多边形下「边界顶点」表格（外环与孔洞 XYZ，增删顶点，添加孔洞草稿，删除孔洞）；「数值平移与旋转」（平移 XYZ、旋转角与单位、旋转中心，二者不能同时待提交）；「整体移动影响与技术详情」。
- 入口与服务点（PointPropertyPanel.tsx:12）：名称、主归属类型、关联设施或区域；位置与技术详情（ID、权威节点下拉）；在画布重新定位；入口另有「建立独立入口…」；服务点：服务类型、接入入口；「接入方式与作业」ServiceSemanticsFields（node_proxy 须填场内转运核算方式与说明；explicit_internal 须选入口节点与逐段道路方向；未声明为草稿）；「接路检查与完整引用」（blocked/unchecked、端点道路、到达语义、内部路径长度、问题、未检查项）。
- 地图信息与多选：地图名称需「应用地图名称」，空名拒绝并保留输入（RF01）；多选时右栏显示「已选择 N 个对象」。

## 14. 撤销/重做（session.ts:21-54，App.tsx:317,635）

## 15. 只读、锁定与不支持

- 整图只读（capabilities.ts:6）：未支持的 behavior 扩展、不受支持的 sr02.planning 载荷、未支持的资产或底图变换；只读横幅，绘制工具禁用（只剩选择、平移、量距），可原样导出。
- 锁定图层：锁定类型可选中查看，被命令触及时整笔拒绝，包括间接依赖（LOCKED_DEPENDENCY，rejectLocked 311）；锁定节点不显示几何柄与宽度柄；锁定底图类型时不能调整底图。
- 临时只读：底图调整中或底图表单有改动、文件关联恢复中、工程未就绪、切换中、保存中。
- 依赖保护：带转向独立几何、多所有者、人工道路带、登记长度等给出具体拒绝代码与 JSON 路径。右栏常驻「保留但未支持」「草稿校验未覆盖」。

## 19. 旧版 UX 痛点（重写要解决）

1. 文件菜单 11 项语义重叠（导入 JSON / 导入副本 / 关联本地 JSON / 关联原文件；保存 / 写回关联文件；文件另存为 / 保存▾另存为 / 浏览器另存为），用户需理解浏览器副本、文件句柄、checkpoint 三套概念。
2. 主要操作藏在排第 5、默认折叠的「绘图与显示设置」里（添加入口、添加服务点、节点工具、三点斜矩形、拓扑吸附、网格吸附、道路显示开关）。
3. 图层显隐锁定与标签模式藏在目录区另一个折叠框。
4. 诊断是折叠框套在默认收起的抽屉里；路径起终点只能用 ID 下拉；服务内部路径要从全图道路 ID 下拉逐段选。
5. 同一功能多入口：接路吸附两处；改宽度四种；旋转两处；复制三种。
6. 上下文行过挤：常驻约 10 个多数禁用的按钮，靠横向滚动。
7. 属性面板层层折叠、长说明常驻。
8. 离开保护弹窗过于频繁；属性必须显式「应用属性」。
9. 死配置：facilityMovePolicy / zoneMovePolicy 持久化但写死为 withStaticContents；新道路默认方向只能经道路预设改；恢复绘图默认配置顺带重置图层隐藏锁定。

11. 信息噪声：状态栏与对话框直接显示哈希、代码、JSON 路径；中文说明长且偏法律措辞。
12. 缺少常见能力：框选、Space 临时平移、逐转向矩阵、储位/资源/厂界编辑命令、工程 ZIP。
