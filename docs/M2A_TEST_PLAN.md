几何预期使用独立的笛卡尔计算，不以调用被测面积/长度函数再与自身比较代替断言。道路split长度比较建议绝对容差1e-9m；若实现需要其他有效范围/容差，须在字段契约中明确后测试。

入口/服务点选用专用或明确已有节点；设施中心不自动成为服务点。测试的fA入口引用nA，nA同时是rAB端点；设施整体移动是否移动nA必须通过显式选项，复制设施不得把rAB及整张路网隐式带入副本。

保存测试继续区分真实IndexedDB、双标签页和OPFS流；原生选择器使用替身时明确标注，不声称完成系统授权手工验收。
