# M1 船厂空间布局编辑器使用指南

本次提供本地米制二维地图和稳定 JSON 的编辑闭环。地图是框架无关的 YardMap，不是画布 JSON；数据契约见 [M0_DATA_CONTRACT.md](M0_DATA_CONTRACT.md)，能力边界见 [M1_CAPABILITIES.md](M1_CAPABILITIES.md)。测试执行结果由 M1 阶段报告记录，不能从本指南中的操作步骤推断测试通过。

## 启动与文件

在 PowerShell 中进入 `paper01/map`，使用 Node 22.18.0 或更高版本：

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

打开终端显示的本地 HTTP 地址。开发服务器只监听本机；地图保存在你选择导入或下载的 JSON 文件中。M1 不需要账户、云数据库或地图上传。生产构建与本地预览：

```powershell
npm run build
npm run preview
```

合法示例为 `examples/M1_synthetic.map.json`，内含 nA=(0,0,0)、nB=(100,0,0) 和 rAB 道路；全部明确标 synthetic。无效示例 `examples/M1_invalid.map.json` 使用不存在的道路终点，校验应定位 `/roads/rAB/toNodeId`。

`examples/M1_simulation_message.fixture.json` 是另一个用途的消息契约夹具：包装字段标记 synthetic、executed=false；message 绑定合成地图的实际摘要。scenario/vehicle 是示例标识，没有对应仿真运行。它不是 map.json，不能作为地图导入。

## 从空图画到可重载的 JSON

1. 点击顶栏 **新建地图**，输入“新地图名称”，再点 **创建地图**。新建布局具有独立稳定 mapId，标记 synthetic，未导出时显示“有未导出编辑”。当前有未导出编辑时，先出现冲突选择，不静默丢失旧图。
2. 选择左侧 **节点** 工具，在画布空白处点击创建节点。切换 **选择** 后点击节点，或从左侧对象列表选择它；右侧显示稳定 ID、名称和 X/Y/Z (m)。例如把两个节点分别设为 `(0,0,0)` 与 `(100,0,0)`，每次点 **应用属性** 提交。
3. 选择 **道路折线**。先点已有起点节点，再在空白处依次点击内部折点，最后点已有终点节点完成。直路直接点起点和终点即可。Esc 取消尚未完成的道路；道路交叉不会自动创建共享节点或转向连接。
4. 选中道路，在右侧查看只读 **派生二维长度**、起点/终点 ID。内部折点列表可逐项编辑 XYZ，使用 **添加内部折点** 或该行 × 增删，最后点 **应用属性**。道路方向可以显式选择“未知（草稿）/起点→终点/终点→起点/双向”，但 M1 不据此计算路线。
5. 使用滚轮缩放，**平移** 工具拖动或鼠标中键拖动平移视窗（中键不会移动节点）；点 **适应地图** 调整可见范围。网格与坐标提示单位为 m，界面 px/m 仅表示显示比例。
6. 用 **选择** 工具拖动节点完成移动。Shift 点击画布对象或左侧对象列表可以多选；选中道路后拖动其端点，可一起移动道路内部折点和端点。共享该节点的其他道路端点同步变化。每次拖动结束仅提交一个领域事务。
7. 点 **撤销** / **重做** 回退或恢复事务。选中后点 **复制**，核对对话框的节点/道路闭包数量，输入 X/Y/Z 偏移 (m)，点 **确认复制**；副本生成新 ID，重做沿用这些 ID。**删除** 只删除明确选中的对象；仍被未选中道路引用的节点会被拒绝，检查器列出依赖。
8. 点 **导出 JSON**，在浏览器下载文件中保留生成的 `.map.json`。外部修改后用 **导入 JSON** 重新选择文件；导入会重新解析、校验和派生，不复用旧画布场景树。

浏览器下载接口不能确认文件最终是否落盘。M1 在发起导出请求后将对应地图摘要记为会话保存基线；请确认下载实际完成并保留文件，若浏览器取消/阻止下载需重新导出。

极端坐标若超出当前视图可投影范围，画布会提示被跳过的图元数量；JSON 和对象列表保留，可通过数值属性调整。

属性输入是待提交表单，只有“应用属性”后才进入地图、撤销历史和 JSON。地图名称另在左侧编辑，点 **应用地图名称** 提交；显示名称和稳定 ID 独立。未应用的表单内容不会被当作地图编辑导出。

### 快捷键

| 快捷键 | 操作 |
|---|---|
| Ctrl/Cmd + Z | 撤销一个领域事务 |
| Ctrl/Cmd + Shift + Z，或 Ctrl/Cmd + Y | 重做 |
| Ctrl/Cmd + S | 发起 JSON 导出 |
| Delete / Backspace | 删除当前选择；有依赖时拒绝 |
| Esc | 取消未完成道路，回到选择工具并清空选择 |
| Shift + 点击 | 多选/取消某个选中项 |

文本输入框、下拉框、可编辑文本或对话框正在操作时，编辑器不截获上述全局快捷键，避免抢走文本撤销与删除。

### 冲突与报错

当前有未导出编辑，再导入合法候选或新建地图时，对话框 **未保存编辑冲突** 提供三条路径：

- **取消**：保留地图、历史和保存基线，默认焦点位于取消。
- **先导出当前版本**：发起独立文件下载，并保持冲突对话框；确认保留下载后可以继续选择重载。
- **放弃编辑并重载**：明确替换为已校验候选，重建派生场景并清空旧图历史。

非法候选在冲突选择前即被拒绝。底部 **检查器** 显示 code、字段路径与处理建议；若问题对应当前地图中可定位的节点/道路，点击可选中并定位。拒绝的候选不会覆盖当前有效地图；其错误路径应在待导入 JSON 中修复。

## 外部修改 JSON 并重载

1. 导出当前地图，保留原文件作为副本。也可复制 `examples/M1_synthetic.map.json`，用文本编辑器修改副本。
2. 在该合成例图中，把 `/nodes/nB/position` 从 `[100, 0, 0]` 改为 `[120, 0, 0]`。不修改 mapId、节点/道路 ID 或端点引用；此次验证特意保持 revision 不变。
3. 使用下面的 CLI 校验修改后的文件，确认没有 error。道路方向、物理参数和未实现能力仍可有草稿 warning。
4. 在浏览器导入修改后的 JSON；如果当前还有未保存编辑，先处理冲突。重新导入后 nB 位置和 rAB 派生长度应变为 120m，内容摘要变化，ID/引用保持。

道路名称是独立文本。示例原名为“100 m 合成道路”，修改坐标不会自动重写它；检查派生长度而不是从名称猜测长度。可另行改名，该操作同样不改变 ID。

不在 JSON 内手加 `lengthM`、centerline、Canvas 变换或视窗字段。道路只保存 fromNodeId、toNodeId、内部 shapePoints；端点位置由 nodes 提供，长度实时派生。坐标用 m，XY 地面，Z 向上；视窗的缩放/平移不改变地图米制坐标。

## CLI 与错误报告

```powershell
npm run map:validate -- examples/M1_synthetic.map.json
npm run map:validate -- examples/M1_invalid.map.json
npm run map:validate -- examples/M1_synthetic.map.json --profile level2_network
```

| 退出码 | 含义 |
|---|---|
| 0 | 草稿结构和已实现语义检查通过；warning 可以存在 |
| 1 | JSON/Schema/语义错误，不能作为有效地图导入 |
| 2 | 命令行参数或本地文件读取错误 |
| 3 | 所请求配置未实现；M1 只支持 draft |

CLI 程序输出纯 JSON。需要脚本解析时，使用 `npm run --silent map:validate -- FILE` 消除 npm 的命令横幅。报告包含 ok/status/profile/issues；有效输入还包含 mapId/mapContentHash/capabilities。Issue 提供 code、severity、jsonPath、message、suggestedAction，并在可获得时给 entityId 与位置。

例如无效样例返回 `DANGLING_REFERENCE`，路径 `/roads/rAB/toNodeId`，退出码 1。这是预期的拒绝结果。未来 Schema 版本不会被自动降级；输入文件或规范化两空格 JSON 超出 10 MiB、嵌套超过 64 层、重复键、非有限数值和未知核心字段均拒绝。紧凑输入也需要满足规范化后上限；超限编辑事务不提交，导出也不能绕过该限制。

若要外部复算内容摘要，遵守数据契约的去 revision、固定键序和紧凑 JSON 规则；它不是下载文件的原始字节哈希。调用现有 CLI 取得摘要可避免不同语言的 JSON 数值与键序编码差异。

## 数据边界

含设施、资源、底图、人工道路边界或未知行为扩展的合法地图，M1 整图只读并完整保留，仍可看节点/道路矢量。界面必须列出未渲染和未检查能力。底图资源未提供也不删矢量模型；单 JSON 不包含图片字节。

map.json、scenario、运行日志/回放与 editor-state 有独立职责。M1 只实现 map JSON 的导入/下载；ZIP、底图标定、自动恢复和另外几类文件的读写属于后续阶段。下载不直接覆盖原始本地文件，浏览器也不会自动监听 Codex 对磁盘的修改；需要显式重新导入。

新建手绘地图保持 synthetic；未知宽高、载荷、速度与容量保持 unknown。导入对象的来源只作为“来源声明”保留，手动修改坐标不会重新核验或自动改写这份声明；如果原坐标有测绘/图纸依据，修改后的字段依据需由用户在外部 JSON 中同步说明，M1 没有来源失效与重新确认工作流。draft 有效不是网络发布通过，也不表示真实船厂可执行、车辆转弯安全或数字孪生已经完成。
