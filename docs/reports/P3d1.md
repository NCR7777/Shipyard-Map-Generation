## 旧版行为（调研）

调研只读旧版代码与测试，结论存于 scratchpad `p3d/old_background_spec.md`，要点：

- 旧版的「校准」只有导入离线脚本生成的校准 JSON（`BG01_background_calibration_v1`，或带清单的旧格式），**没有任何交互校准**：不能点两点定比例，也不能按控制点拟合。新建描图时没有校准 JSON，只能靠在数值表单里猜宽度。
- 没有「从图片新建地图」：新建地图是空图，旧版自己的测试是克隆一张真实地图再清空来模拟。
- 添加流程：选图片（可附校准 JSON）→ 候选卡片 →「添加此底图」；未校准时按**节点**范围放置。
- 调整：进入调整模式才能动（离开即锁定），画布上移动、拉角（可保持宽高比）、旋转柄；方向键 0.1 m / 1 m；数值表单（左上角 X/Y、宽、高、角度、比例 %）点「应用」提交，只处理改过的字段。
- 替换：保留原变换，像素尺寸不同时地面范围随之改变；重新关联：同 SHA 只存字节，地图不变；删除：只删图层，图片与字节保留。
- 内核命令 `addBackground` / `updateBackgroundTransform` / `deleteBackground` / `replaceBackgroundAsset` 与 P0 原样移植，本段只在界面层使用它们；每次成功的命令都由内核追加一条「底图编辑沿革」来源。

## 范围与改动

- **添加底图…**（文件菜单、图层页「底图」组、空白地图的画布提示）：选一张 PNG / JPEG / WebP，可同时选校准 JSON。
  - 图片先按字节核对格式、尺寸、SHA-256 并解码，**字节先存入本工具的浏览器数据库，再提交地图命令**，保存的地图不会指向本浏览器没有的图片；数据库不可用时照常添加并提示下次需重新选择。
  - 有校准 JSON 且通过：按文件放置，记为「按校准文件放置」（method `affine`，保留控制点）。
  - 选了校准 JSON 却不能用于这张图片（坐标框架不符、图片不符、不是校准文件等）：**不添加**，提示原因与代码，并说明不选校准文件即可先手动放置。
  - 没有校准 JSON：初始位置是猜测——地图已有矢量或其他底图时，缩放到覆盖其范围并居中；空白地图按 1 米/像素、左下角放在原点。添加后画面对准新底图，并**直接进入调整**。
  - 同一张图片（SHA-256 相同）已是底图时不添加：读取后检查一次，字节入库后按当时的地图再检查一次（入库期间撤销可能让同图的图层回来）。已有相同图片声明（其他图层删除后留下的）则复用它及其来源。
  - 地图只读或「底图」「图片资源」「来源」类型被锁定时，在读取之前就拒绝，不读、不存字节。
  - 一次添加是一个撤销步骤。读取与解码期间提示「正在读取…」；同一时间只处理一张图片（添加或替换），期间再选会被拒绝并说明。
  - 「底图」类型被隐藏时添加未校准图片：照常添加，提示里同时说明暂不能调整的原因。
  - 校准文件的坐标框架带地理锚点而地图没有（新建地图都没有）时，提示直接说明是锚点不同、校准文件在这张地图上用不上，以及可以怎么做（见已知限制）。
- **调整模式**（「锁定」的实现）：底图平时锁定——画布上点不中、拖不动，数值只读。从图层页的「调整底图」、属性栏的「调整位置与比例」进入；属性栏「完成调整」、Esc、选中别的对象、换工具、换地图、底图被隐藏或锁定、地图变为只读时结束。
  - 画布：拖动图片移动（毫米取整）；拖四角缩放，对角固定，默认保持宽高比，Shift 临时切换；拖顶部圆柄旋转（绕中心，Shift 按 15° 取整）。拖动中显示预览与尺寸 / 角度标签，松开时一次提交；Esc 或窗口失焦取消，不留记录；松开处与起点相同不记录。调整时所有按压只作用于这张底图，不会选中或拖动矢量。
  - 方向键微调 0.1 m，Shift 1 m（焦点须在画布上，与微调选中对象一致）。连续微调是一个撤销步骤，并且**在地图里只留一次改动**：后续每一步都从这串微调开始前的状态重新施加累计后的绝对位置（见审查修正 B1）。位置按「开始处 + 步数 × 0.1 m」计算，不在已有舍入误差的位置上反复加 0.1，所以一串微调回到起点时位置与原来完全相同，也不留撤销步骤。
  - Delete 删除这层底图（可撤销），焦点须在画布或这层底图自己的控件上（属性栏、图层页中正在调整的那一层）；Backspace 不删除；焦点在其他控件上按 Delete 或 Backspace 只提示删除方法。
  - 选中底图但未调整时，方向键与 Delete 提示「先进入调整」或「用删除底图按钮」，不再显示通用的「只能查看的对象」拒绝。
  - 属性栏数值：左上角 X / Y、宽、高（可勾选保持宽高比）、角度（逆时针）、米/像素。逐字段在 Enter 或离开时提交（与 P2d 一致），Esc 恢复；**只改动输入的那一项**，未碰的数保持完整精度，输入的左上角坐标原样存储。
  - **量距定比例**（新增）：点「量距定比例」，在图上点一段已知实际长度的两端，输入实际长度，第一点不动、整图等比缩放；画布上显示两点与图上距离。点在图外被拒绝并说明；已有两点时再点图上即从这一点重选；长度框里按 Esc 直接取消量距。
  - 已按校准文件放置的底图，调整后内核会记为手动放置（控制点保留），属性栏在调整时提示这一点。
- **替换图片…**（图层页、属性栏）：换成另一张图片，**保持原来的地面范围**——左上角与宽度不变；宽高比与原图相差 1% 以内时高度也不变，否则不拉伸图片、高度随之改变，并提示检查对齐。替换与重新适配由编辑网关的 `applyAll` 作为一个事务提交，是一个撤销步骤，与两次提交之间隔多久无关。选到同一张图片时只重新载入，地图不变；选到另一层已在用的图片时拒绝（与添加的规则一致）。调整时替换，调整不中断。
- **删除底图**（图层页、属性栏、调整时在画布或该层控件上按 Delete）：只删图层，图片声明与字节保留，撤销即恢复原样。
- **重新关联**：沿用 P1B（菜单项改名为「重新关联底图图片…」）。
- **修正 P1B 缺口**：图层表中「底图」类型的隐藏与锁定对图片生效（此前表中有这一行，但隐藏不影响图片、锁定不影响操作）。隐藏类型时全部底图不画；锁定类型时不能添加、调整、替换、删除。
- **图层页**：每层显示放置方式、像素尺寸与米/像素；「底图」组在没有底图时也显示，提供「添加底图…」。
- **属性栏**：选中底图（对象目录）显示图片信息、载入状态、放置方式与位置数值。

## 设计决定

- **锁定即调整模式**：不单独提供每层的锁定开关——底图只在明确进入调整后才能动，这正是锁定的目的；另设一个开关只会多一种「解锁后忘了锁」的状态。旧版也是进入调整即解锁、离开即锁定。
- **不用候选卡片**：旧版选图后要再点「添加此底图」。这里直接添加（一个撤销步骤）并进入调整，出错时不添加并说明原因，少一步确认、结果立即可见。
- **校准文件不能用就不添加**：旧版对「没有绑定这张图片」的 JSON 按未校准添加（候选卡片上会显示未校准状态）；这里一律拒绝，免得同时选了校准文件却得到未校准的底图。
- **替换保持地面范围**：旧版保留原变换，换一张分辨率更高的同范围图片会让底图变大；描图时用户期望的是同一块地面换一张更清楚的图。
- **量距定比例放在调整模式里**：定比例改的是底图，只在底图可动时提供；第一点不动，便于先把一个已知点对准再定比例。
- **初始位置按全部内容范围**（旧版只看节点）：建筑、区域、道路也算。
- **编辑网关的两个新入口**（`src/app/state/edit.ts`）：`apply(…, restart)` 用于设置绝对值的命令，一串合并的操作从开始前的状态重新施加，整串只留一次改动（不只是一个撤销步骤）；`applyAll(commands, label)` 把几个命令作为一个事务提交，全成或全不成。两者都照常经过内核校验与锁定检查。
- 内核目录（`src/domain`、`geometry`、`topology`、`validation`、`compiler`、`editor`、`adapters`）未改动。

## 已知限制

- 控制点配准（图上点对应地图已知点，相似 / 仿射拟合与残差）在 P3d2；内核的变换命令会把配准方式记为手动并保留旧控制点，记录方式在 P3d2 先定。
- 已按校准文件放置的底图一经调整即记为手动放置（内核行为），原控制点保留在图层中但已不对应新位置。
- **每次底图改动在地图里留一条沿革来源，且越来越大**（内核行为）：每条来源的描述含改动前图层的全部 `sourceRefs`，所以地图体积随底图改动次数按平方增长。连续微调已合为一次（B1），但每次拖动、每个字段提交、每次量距、每次替换仍各留一条（替换两条）。审查者在真实韩华地图（约 4 MB）上测得约 575 次改动触及 10 MiB 上限，之后地图几乎不能再编辑，界面也无法清理这些来源。正常调整一张底图远达不到这个次数，但这是内核的设计问题，需在 P3d2 之前由内核负责方裁决（例如沿革只记增量、或同一图层的连续改动合并为一条）。
- **校准文件只能用于坐标框架（含地理锚点）与之完全相同的地图**：新建地图没有地理锚点，用不上带锚点的校准文件（真实韩华校准文件的锚点为 EPSG:32652）。目前只能手动放置并量距定比例，或把底图加到从原工程导入的地图上。「新建地图时采用校准文件的坐标框架」列入 P3d2。
- 内核在字节入库之后才拒绝的添加或替换（事先检查不到的情况），会在浏览器数据库里留下没有地图引用的图片字节，只占存储。
- 导出副本只含地图 JSON，不含图片；换浏览器或清除数据后需重新选择原图（按 SHA-256 匹配）。
- 拖动与旋转不吸附网格或矢量；图像在屏幕上很小时，四角与旋转柄会挤在一起，需先放大。
