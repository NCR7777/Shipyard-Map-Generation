# ADR-002｜画布改为单张原生 canvas，移除 Konva

状态：已采纳（2026-09-24，P1），取代 ADR-001 第 2 节。

## 决定

- 画布只用一张原生 `<canvas>`，每个动画帧只画一遍，所有变化合并到这一次绘制里：
  - 网格、节点、入口与作业点标记、单向箭头、标签、框选框在屏幕坐标下绘制；
  - 静态地图（按样式分组的 Path2D 批次）与选中、悬停高亮在世界坐标变换下绘制。
- 像素比与尺寸由渲染器自行处理。
- 点选、框选、吸附都走几何内核，不依赖任何图形库的命中检测。
- 移除依赖 `konva` 与 `react-konva`。

## 依据

- 按 ADR-001 第 2 节实现 Konva 分层版后，Konva 实际只剩「管理画布和像素比」一件事：自定义 Shape 直接拿原生上下文绘制，事件与命中检测都不经过 Konva。按 Ponytail 原则，原生平台能力足够时不保留依赖。
- 生产构建的主包由 705 kB 降到 519 kB（gzip 216 kB 降到 159 kB）。
- 同机同一测量方法下，四层画布版与单画布版的平移帧间隔相同，而这一测量受输入事件节奏限制，所以性能不是本决定的理由；与 `../map` 的正式性能对比见 P1 性能验收记录。
- 后续阶段需要的控制柄（顶点、矩形角、曲线切向、宽度）命中判断本来就是几何计算，不需要图形库的事件系统。

## 放弃的方案

- **保留 Konva 分层**：没有收益，多一份依赖，也多出几张画布需要合成。
- **WebGL/PixiJS**：没有测量证据表明需要，文字标签更复杂，还要新增依赖。
