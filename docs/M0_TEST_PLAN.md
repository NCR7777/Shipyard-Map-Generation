## 运行矩阵

在 `paper01/map` 使用当前锁文件执行：

```powershell
npm ci
npm run typecheck
npm run lint
npm run test
npm run test:integration
npm run build
npm run test:e2e
npm run map:validate -- examples/M1_synthetic.map.json
npm run map:validate -- examples/M1_invalid.map.json
npm run dev -- --host 127.0.0.1
```

`dev` 验证需记录启动成功与本地 HTTP 页面可访问，然后结束测试进程。无效样例的退出码 1 是预期的拒绝结果，不写成执行失败。CLI 参数/文件错误预期 2；未支持配置预期 3；合法草稿预期 0。纯核心测试无需启动 Vite 或浏览器。

浏览器验收使用实际节点绘制、折线点击、拖动和表单；不能仅向内部状态注入 JSON 后声称绘图交互通过。下载文件通过外部 Node 脚本改变坐标，然后用文件选择接口重新导入。记录浏览器与运行时版本；无法安装浏览器或启动本地服务时，保留该限制，不能以 build 替代 e2e。

## 数据与判定

- 合法例图 `M1_synthetic.map.json` 明确标为 synthetic；100m 道路来自示例坐标，不作为实测船厂或调度性能证据。
- 无效例图 `M1_invalid.map.json` 包含悬空道路端点引用，期待定位到该道路端点字段，不能只报“地图非法”。
- 非有限数、重复键、非法核心字段等夹具由测试直接构造；扩展夹具必须声明命名空间并检查内容完整保留。
- 摘要判定分别检查：revision 单独变化不改变摘要；节点/折点/来源/资产/扩展变化改变摘要；视窗变化不改变地图导出。
- M0 先完成契约与纯核心最小验证并进行独立只读审核；控制器裁决通过后进入 M1。M1 独立审核后只提交 map 相关文件；推送结果独立于本地测试结果记录。

未纳入本次通过标准：A12—A14 的完整网络/设施行为，A16—A27 的完整底图、资源、发布和预览，A30 的历史迁移实现，A32 的三套完整布局，A33 的规模性能承诺。涉及已声明数据的基础结构与引用检查仍应执行；排除的是后续运行或编辑能力。
