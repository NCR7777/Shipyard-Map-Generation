# 验收测试清单

这些是待实现的自动化/人工验收要求，不是已执行的测试结果。每项记录所属阶段、运行方式、实际结果；可按实现选择合理测试框架。建议单元测试+CLI集成+Playwright浏览器端到端。

## 基础数据与往返

A01：新建地图并保存，ID与单位存在；在无React/DOM环境解析、校验成功。

A02：建立nA=(0,0,0)、nB=(100,0,0)及无内部折点的道路，派生长度为100m。缩放/平移画布后长度与JSON坐标不变。

A03：导出后由外部脚本将nB改为(120,0,0)，即使未手工修改revision，重载后长度为120m、地图摘要变化、旧缓存失效、节点与道路ID保持。

A04：导入→不编辑→导出的规范化语义相等；反复往返10次不累积坐标误差。扩展字段被保留，几何顶点顺序不被排序。

A05：非法JSON、重复键、1e400等非有限数、悬空引用及未知核心字段有可定位错误；失败导入不替换当前有效地图。

A06：鼠标拖动100个中间帧，撤销一次恢复拖动前状态；重做恢复拖动后状态。更改对象名称不更改ID。

A07：复制包含道路与节点的选择集，复制部分的ID重新生成且内部引用正确；不误连回旧节点，除非操作中明确选择保留外部连接。

A08：不受支持的schemaVersion不得被悄悄降级保存；扩展行为不受支持时，相关发布能力被阻止。

## 几何、连接与设施

A09：两条二维相交道路没有共享节点时，不自动互通；同层未解释平交产生校验问题。用户确认拆分连接后，图可达性与引用同步更新。

A10：高程/层级明确不同的交叉道路不自动连接；只改颜色不能解除或建立连通。

A11：移动共享节点，两侧道路端点随之更新；人工道路边界冲突被提示，不能继续使用过期边界。

A12：单向道路不能反走。明令禁止的入弧→出弧转向在路线计算过程中被排除，不能只在输出后隐藏。

A13：设施中心与设施入口不同。到设施的路线终点是指定入口/服务点，缺入口绑定时发布报错；合法内部通道显式建模后可以通过。

A14：自交外环、非法孔洞、零长度边和未授权穿越水域/障碍均报告；不能只看颜色判断障碍。

A15：删除已被道路/服务点引用的节点时显示依赖并拒绝或确认级联；撤销恢复全部依赖关系。道路拆分保留/正确转换限行与资源引用。

A16：只有指定OD必须可达；辅助区域孤立不能被误当作所有地图必须强连通。主要装卸点不可达时有具体原因。

## 底图与资产

A17：图中200像素线段以100m标定后，量测为100m；图像旋转、画布缩放和重载不改变这一结果。界面说明这是比例标定，不是独立精度证明。

A18：仿射控制点共线或近退化时阻止/警告。三个点恰好拟合时不把零残差当测绘精度；存在独立检查点时单独统计检查误差。

A19：换背景标定只改变背景；要批量改变已描绘对象时需确认并可完整撤销。

A20：zip导出在清空浏览器缓存后可以重新打开图形与底图。只有map.json时，缺底图只产生资产警告，不删除道路与设施。

A21：拒绝zip路径穿越、超限解压及非法媒体类型；恶意标签文本不能执行脚本。未经允许无地图上传或遥测请求。

## 资源、假设与预览

A22：双向道路编译成两个方向弧，但按设置共用同一道路容量资源；不同资源的非冲突动作不被自动锁成一个全局互斥。

A23：道路宽度unknown时，拓扑预览可明确标未知；需要该参数的level2编译拒绝或要求显式假设。输出记录假设来源，不把null当无限宽。

A24：有100m道路，预览速度2m/s，仿真时钟自由流时间为50s。不同渲染帧率不改变结果。没有完成扫掠检查时，不显示“车辆几何安全”。

A25：改变地图后进行新的路线查询，过期Worker结果不得覆盖新图；旧回放仍绑定旧mapContentHash，缺旧快照时提示无法可靠回放。

A26：隐藏道路图层只影响显示，不改变路由；将道路设为动态封闭应通过scenario/event而非隐藏操作。

A27：同一map+compileProfile+编译器版本产生相同规范化编译输出；派生长度不从用户可编辑旧缓存读取。

## 工程、外部编辑与扩展

A28：纯核心在Node环境执行，无浏览器依赖；CLI错误以非零退出码和结构化报告输出。核心不依赖渲染器内部节点类型。

A29：外部修改JSON且浏览器仍有未保存编辑时，保存不静默覆盖；给出重载、另存或显式冲突解决路径。文件系统API不可用时仍可普通导入和下载。

A30：map.json、scenario和回放可独立读取；schema迁移保留原件、生成差异，并通过合法/非法历史样例测试。

A31：地图scene转换测试原点、3个基向量、1m尺度、朝向和往返。未来三维适配器不允许把本地Z-up误当Y-up。首版仅有接口时，标为documented_interface而非implemented。

A32：至少3套synthetic布局可独立打开；新增布局无需修改渲染代码。切换布局不会串用上个布局的资源、任务绑定或预览缓存。

A33：声明环境下进行规模基准，记录输入规模与实际时间，不把未经测试的目标作为性能结果。

A34：完整执行typecheck、lint、unit、integration、e2e和build；记录失败/未执行项，禁止通过删除断言掩盖问题。
