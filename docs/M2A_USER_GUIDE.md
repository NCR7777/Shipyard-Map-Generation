# M2A 空间编辑使用指南

本指南保留 M2A 阶段的空间编辑流程。新增服务点到达语义、0.2.0 兼容和未应用输入保护以 [M2A.1 使用指南](M2A1_USER_GUIDE.md) 为准；本文件中旧的暂存输入切换限制已经被该增量版本更新。历史验收见 M2A 阶段报告；地图草稿有效不代表现场运输安全。

## 启动和保存

在本目录使用 Node 22.18.0 或满足 package.json engines 的版本，运行 `npm ci`，然后 `npm run dev -- --host 127.0.0.1`。打开终端显示的本地地址。不要直接双击源码 index.html。

“保存工程”和 Ctrl/Cmd+S 将已提交地图保存到本站点的浏览器工程；成功编辑后自动保存草稿，刷新后恢复。导出 JSON 只下载备份，不代替浏览器保存，也不代表关联文件已写回。输入控件里仍能使用保存快捷键；存在未应用属性、绘制或操作表单时，会说明只保存已提交地图，允许返回完成输入。

浏览器可能清理站点数据。用 JSON 导出另作备份；完整带资源 ZIP 往返属于 M2B，当前 ZIP 入口明确禁用。系统文件选择器与写回属于按能力增强；手工检查见 [原生文件验收](M11_NATIVE_FILE_ACCEPTANCE.md)。

## 绘制设施和区域

1. 新建并命名地图。手工新建的布局始终标为 synthetic，不自动变成实测地图。
2. 在左栏选择设施类型或区域类型，再选择矩形或多边形工具。设施包括厂房、堆场、总组、坞区、码头等；区域包括作业、缓冲、等待、水域、障碍、禁入和可行驶。
3. 矩形按两个对角点创建；多边形逐点绘制，点击首点或 Enter 完成，Esc 取消。网格吸附可以选择 1 m、5 m 或 10 m，节点吸附仅改变候选坐标，不自动建路网连接。
4. 选择对象后通过属性面板精确修改米制几何及顶点。外环必须逆时针、孔洞顺时针并显式闭合。非法修改显示带字段位置的错误，保留原有效地图和撤销历史。

缩放和平移只改变视图。设施边界不等于车辆入口，区域名称或显示颜色不会创建容量、可通行路径或避障规则。绘图面积、包围盒和道路长度由权威几何派生。

## 入口与服务点

先选设施，点击“添加入口”或“添加服务点”。入口必须指定所属设施；服务点可指定设施、关联入口和服务类型。位置明确选择已有节点，或输入新专用节点的 X/Y/Z 米制坐标。软件不会把设施中心当成装卸点。

点对象只保存 nodeId，坐标只保存在节点中。设施成员列表与点的设施引用通过一个事务同步维护。共用节点意味着移动该节点会改变它关联的所有点和道路端点；独立服务位置应使用独立节点。修改关联也通过属性面板提交，违反归属一致性时会拒绝整个事务。

## 移动、旋转、复制和删除

直接修改边界顶点仅更新多边形，不会搬动关联节点。整体移动或旋转设施前，先查看“设施移动策略”：仅移动边界，或者边界和关联节点一起移动。界面列出受影响道路；实际拖动仅预览，松开鼠标提交一个可撤销事务。Shift 点击多选；旋转角度为弧度，正值绕 Z 轴在世界 XY 中逆时针。

复制对话框列出复制闭包和米制偏移。设施会带上其入口、服务点及所需节点并重映射新 ID；外部道路不复制，不连接到新副本。单独复制点并保留其原设施归属需要显式勾选。重做复用本次已分配的 ID。

删除设施默认拒绝删除其仍在使用的成员；可明确选择一并删除成员点，以及只清理不再使用的节点。道路仍使用的节点保留。显式选中删除的节点若还有未选依赖，则拒绝整个删除并指出引用字段。复杂资源依赖继续受保护。

## 拆分道路和物理参数

单选道路，点击“拆分道路”，填写从 from 端沿道路 XY 折线量起的距离。默认创建切分节点；可明确复用切分位置 1e-6 m 容差内的节点。成功后原道路替换为两条新道路，方向、物理值和来源保留，历史 ID 映射写入声明的 metadata 扩展。存在尚不能安全重写的资源、转向或扩展引用时拒绝。

普通交叉、重叠和吸附不自动拆分或连接。只有显式节点引用和未来的转向配置定义可通行关系。近邻提示用于发现可能漏接的对象，不证明路网完整。

道路属性的“物理参数与来源”提供宽度、净高、承载和速度的 known、unknown、unrestricted、not_applicable 四种状态。known 需要正的有限数值；没有来源的新数值登记为 design_assumption。其他状态不会变成零，也不会默认填入真实限制。

## 外部 JSON 与验证

JSON 导出后可直接用文本编辑器或 Codex 修改。重新导入使用与 CLI 相同的解析、结构校验、语义校验和场景投影；没有浏览器专用的宽松地图格式。即使 revision 未修改，内容摘要仍会改变。失败导入、取消冲突和失败命令保留当前有效地图。

```text
npm run map:validate -- examples/M1_synthetic.map.json
npm run map:validate -- examples/M2A_synthetic.map.json
npm run map:validate -- examples/M2A_invalid_polygon.map.json
```

最后一条是故意无效样例，应退出 1 并定位自交边界。合法 synthetic 示例含 60 m × 30 m 厂房、20 m × 20 m 等待区、入口、服务点和两条道路；通过 `node --import tsx scripts/generate-M2A-examples.ts` 由实际领域命令重新生成。

外部文件冲突和并发标签页冲突均需要明确处理。缺少底图不会删除矢量数据；存在本轮未支持的底图、资源或行为时保留整图只读保护及能力说明。几何上限、容差和命令闭包见 [M2A 领域契约](M2A_DOMAIN_CONTRACT.md)。

## 当前编辑边界

未应用表单及未完成绘制不属于地图事务，也不跨刷新保存。切换选中对象或绘制工具可能舍弃当前暂存输入；请先应用属性或完成绘制。撤销历史只在当前编辑会话内保存，刷新后恢复地图正文和视窗。系统文件授权尚需按手工步骤核验，自动测试不代替任意本地磁盘授权实测。
