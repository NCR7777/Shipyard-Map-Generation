# 连续添加建筑入口（2026-09-16）

基线：本地 `43d0c47ecb4af99b16625022b42c223bb76d82fa`。沿用原 React/Konva 编辑器、外边界投影、领域命令、撤销历史和工程存储。

## 使用方法

1. 选中一个建筑，点一次“添加入口”。
2. 沿高亮外边界连续点击。绿色圆点表示实际吸附位置，每次有效点击立即创建一个入口及其独立节点，无须逐个确认。默认采用该建筑内首个未使用的“入口001、入口002……”名称。
3. Ctrl+Z 逐个撤销，重做后也可继续放置。Enter、Esc 或“完成添加入口”结束；切换工具或选中其他对象也会结束。已经创建的入口保留，可以在连续模式中直接保存。
4. 后续用道路工具从入口节点接路。需要自定义名称、绑定已有节点或立即接路时，点“单个入口与接路设置”，使用原有表单及接路预览。

画布沿实际外环吸附，孔洞和远离边界的位置不会创建入口。双击和点击同一建筑的已有入口不会重复创建。普通单点设置中已有名称、点位或接路候选时，不能直接切换连续模式丢弃输入；其未应用输入保存保护继续有效。

## 实现与保护

- 每次点击复用一个 `addAccessPoint` 原子事务，入口引用、独立节点和撤销一起处理；不生成道路，不移动建筑，不修改已有节点。
- 连续模式复用现有 point activity。成功编辑、撤销或重做后刷新编辑版本上下文，避免第二点使用过期版本。
- 连续模式仅保存“等待下一次点击”的状态，已点击坐标立即提交；保存继续读取现有同步地图快照。普通单点候选仍视为未应用输入。
- 内部编辑只允许为当前建筑新增独立入口。撤销到所属建筑或区域已不存在时，清理失效的内部编辑状态，后续绘图可正常继续。
- 项目恢复复用原交互重置；保留锁层、有限坐标、引用、来源和版本一致性校验。没有新增地图、历史或存储系统。
